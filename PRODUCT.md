# Product

## Register

product

## Users and purpose

Oak players use a desktop or mobile browser to explore the shared Minecraft world, see who is online, and chat with the server. Map exploration is the primary task; server status and conversation support it.

## Personality and principles

Preserve the restrained forest theme required by AGENTS.md. Keep player-facing language in Brazilian Portuguese. Favor reliable navigation, readable controls, and a quiet interface over decorative effects. Avoid visual redesign during operational fixes. Adapt resource consumption to the device before loading the map.

## Accessibility

Preserve keyboard access, visible focus, descriptive iframe titles, status announcements, and the single-column mobile layout. Performance improvements must keep map interaction available.
